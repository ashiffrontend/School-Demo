## 🌟 Overview

**Bright Future Public School** is a responsive, accessible, high-performance static website built for a premier CBSE-pattern educational institution located in New Delhi. The site covers classes from **Nursery through Class VIII**, emphasizing experiential learning, STEM innovation, and student care.

This project is built as a **Pure Static Web Application** utilizing modern HTML5, clean CSS3 (without framework dependencies), and ES6 Vanilla JavaScript. It is 100% ready for instant deployment on **Vercel**, **GitHub Pages**, or any static CDN.

---

## 🚀 Key Features

- **Apple-Inspired Design System**: Clean typography (`Outfit` and `Plus Jakarta Sans`), glassmorphism navigation, balanced spacing, and subtle layered shadows.
- **Dark Mode & Light Mode**: Seamless theme toggling with smooth transitions and persistent `localStorage` preference memory.
- **Scroll Progress & Sticky Navbar**: Real-time reading progress bar and blur-backdrop sticky header.
- **Classes Nursery to Class VIII**: Complete academic grade cards with age criteria, subjects, activities, and mentors, plus interactive category filtering (Early Years, Primary, Middle School).
- **Online Admission Registration Portal**:
  - Comprehensive form validation for student & guardian data
  - Student photo upload placeholder with live client-side preview
  - Automated application reference number generator (`BFPS-2026-XXXX`)
  - Success modal with instant receipt print/download functionality
- **Interactive Photo Gallery & Lightbox**: Filterable by Campus, Labs, and Events with full-screen lightbox modal and keyboard navigation.
- **Notice Board & Live Event Countdown**: Real-time ticker, digital notice circulars, and event countdown timer.
- **Interactive FAQ Accordion**: Smooth expandable accordion answering top parent queries.
- **PWA Offline Ready**: Web App Manifest (`manifest.json`), service worker caching (`service-worker.js`), and install app button.
- **SEO & Schema.org**: Complete School structured data (JSON-LD), Open Graph cards, Twitter cards, `sitemap.xml`, and `robots.txt`.
- **Floating Contact Actions**: Quick access WhatsApp inquiry and direct phone call buttons.

---

## 🛠 Technology Stack

- **HTML5**: Semantic document hierarchy, ARIA attributes, structured metadata.
- **CSS3**: Custom properties (CSS variables), Flexbox, CSS Grid, Glassmorphism (`backdrop-filter`), animations.
- **Vanilla JavaScript (ES6)**: DOM manipulation, IntersectionObserver for animated count-ups, touch/click event handling, PWA service worker registration.
- **Zero Frameworks**: No React, No Tailwind, No Bootstrap, No external bundler required.

## ⚡ Deployment on Vercel

This repository is zero-config static. To deploy on **Vercel**:

1. Push this folder to your GitHub repository.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository.
4. Leave **Build Command** and **Output Directory** empty (Vercel automatically serves root static files).
5. Click **Deploy**. Your website will be live in seconds!
